# CryptoVault — Release Security Checklist

Перед использованием mainnet:

- [ ] Release build проходит без ошибок.
- [ ] APK подписан вашим собственным keystore.
- [ ] Keystore не находится в репозитории.
- [ ] GitHub token не находится в исходниках.
- [ ] Seed не появляется в Logcat.
- [ ] Приватные ключи не логируются.
- [ ] Все реальные операции требуют явного подтверждения.
- [ ] Биометрия/device credential включена.
- [ ] Chain ID проверяется.
- [ ] Адрес назначения показывается пользователю перед подписью.
- [ ] Сумма и комиссия показываются пользователю.
- [ ] ERC-20 approval проходит через отдельное предупреждение.
- [ ] Unlimited approval не подписывается без явного предупреждения.
- [ ] Перед broadcast выполняется simulation/validation, где поддерживается сетью.
- [ ] RPC работает только через HTTPS.
- [ ] Проверены pending/confirmed/failed состояния.
- [ ] Сделана минимальная mainnet-транзакция.
- [ ] Независимый security audit выполнен до хранения существенных средств.
